Generated by `scripts/f5_reach_run.py` and `scripts/f5_reach_report.py` from `runs/f5/reach/` (not committed). Procedures, inputs and the search are those of the committed prereg/16. Training-seed data only; nothing was tuned; prereg/14 is unchanged.

## 1. What is measured

- dA = 39.5 deg x sum_m sigma_m (s_mL - s_mR) over the 16 Lindsay `lateral` MNs (one neuron per type and side). 12.5 deg needs sum = 0.316; the trivial bound |s| < 1 gives |dA| < 632 deg.
- D = window mean of c x dA per trial (c = intended direction); reach = mean D over the trials. Reachable if any procedure reaches >= 12.5 deg.
- I1: F3a-3 drives DNa04_L_25, DNa04_R_25, DNa15_L_25, DNa15_R_25, DNa04_L_100, DNa04_R_100, DNa15_L_100, DNa15_R_100 on the DNg02 baseline; 200 intervals, window 100-199. I2: 80 recorded FlyWire DN records at 60 deg/s (rot_left / rot_right, data seeds 0-39) through the `ensemble` bridge (225 units, 305 BANC targets); 300 intervals, window 120-299. The prereg/14 target at 60 deg/s is 6.25 deg.
- `shuffled`: seed 20261501, 30,203,330 accepted swaps of 31,476,641 tried (rejected: self-loop 4,158, duplicate 1,269,145, same edge 8), 16 s. Check: degrees equal True, signs per presynaptic neuron equal True, no self-loops True, no duplicates True; edges in place 0.009 %, pairs kept 1.98 %.

- For `true` on I2 the last evaluation (step 200, reach 11.39 deg) is below 12.5 deg because the search became unstable: its smallest D is -188.77 deg, i.e. some trials turn hard the wrong way, and 50 % of trials are >= 12.5 deg. At step 150 the parameters (inside the prereg/14 bounds) gave a reach of 93.44 deg with every trial >= 12.5 deg in the intended direction (smallest D 25.03 deg). So a bounded parameter set that reaches 12.5 deg on all 80 recorded trials exists; the amplitude is not capped below 12.5 deg.
- Raising every gain to G_MAX (P1) gives only 2.52 / 2.03 deg (I1 / I2): the amplitude comes from selective gains (after P2 about 32 % of gains are above 1.9 and 25 % below 0.1) and recurrent amplification, not from a uniform scale.
- The search reaches far beyond the target (hundreds of degrees, near the |s| -> 1 saturation of the readout MNs). The open risk for training is therefore not a ceiling but the start: the untrained output is 0.49 deg on I2, and the ascent passed through unstable, latched states.
- The `ensemble` bridge has 225 units (221 by exact type, 4 by family; prereg/10, prereg/11). prereg/14 and docs/10 write 224, which is the unit count of the derangement bridges. prereg/14 is not edited; this is recorded here.

### 5.3 Options (prereg/16 section 6: listed because the registered verdict for `true` on I2 is 'not reached'; none is applied, prereg/14 is unchanged)

| option | pros | cons |
|---|---|---|
| keep prereg/14 as is | 5.2 shows bounded parameters that reach the target on all trials; no change to the registered model | training starts at 4 % of the 12.5 deg target (I2); the ascent passed through unstable states, so a training run may be slow or unstable |
| one trainable readout scale k (dA = k x G1 x R_OUT x sum), shared rule for every arm | removes the start-scale gap directly; one parameter; same for all arms, so the comparison stays fair | a free output gain is a fitted (`F`) constant on the readout that docs/08 fixed; it can absorb part of what the network should learn; mlp / linear already have an equivalent freedom |
| larger G_MAX (for example 5 or 10) | more headroom per edge; no new parameter type | changes a registered bound; makes runaway recurrent excitation easier (more instability); still a uniform rule that does not address the start scale |
| input scaling (smaller R_IN, i.e. larger clamp per Hz) | larger DN drive into the VNC from the start | changes the registered rate scale; pushes the clamped DNs out of (0, 1) at high rates; affects stage B/C consistency with the bridge |
| initialise theta from a short P2-like warm-up | — | uses the objective before training: not acceptable as a model change, listed only to be excluded |
